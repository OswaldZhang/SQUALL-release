# SQUALL

<img src="https://squall.readthedocs.io/en/latest/assets/logo-SHnFptD4.png" alt="SQUALL Logo" width="250" align="right" />

For SQUALL pretraining, the data are available at:  
<[https://zenodo.org/records/17318279](https://zenodo.org/records/20587149)>

Please refer to the following resources for more information:

- Model source code:  
  <https://github.com/OswaldZhang/SQUALL-release>
- Usage documentation:  
  <https://squall.readthedocs.io/en/latest/#/>
- Pretrained weights:  
  <https://huggingface.co/zongxu/SQUALL>

If you encounter any problems accessing the model, feel free to open an issue on the GitHub repository or contact us directly at [zongxu.zhang@stu.pku.edu.cn](mailto:zongxu.zhang@stu.pku.edu.cn) and [zexianzeng@pku.edu.cn](mailto:zexianzeng@pku.edu.cn).

Suggestions and feedback are very welcome!
